## The Video Script

### 1. Voiceover Narration Script
This is the clean text you will read during voice recording/teleprompting.

**Riya (Intro Hook at 0.0s - 10.0s):**
"In this video, we will learn the difference between prompt engineering and context engineering — and why context engineering is the real skill for building smart AI agents."

**Presenter:**
"Most people think AI is all about writing the perfect prompt. But the truth is, even the best prompt will fail if the AI does not have the right information.

Prompt engineering is about writing better questions. Context engineering is much bigger — it is about building a complete information environment for the AI before it even starts thinking.

Think of it like this. Prompt engineering is asking your assistant a smart question. Context engineering is giving your assistant all the files, emails, calendar, and background information they need before they answer. The better the context, the better the answer.

What goes into context? First, the system prompt — the instructions that tell the AI who it is and how to behave. For example: 'You are a technical writer. Be formal and precise.'

Second, retrieved documents. The AI fetches real files from a knowledge base — like pulling product specifications for a project.

Third, tool outputs. The AI uses external APIs to get live data — like checking your calendar to find free time, or checking the weather for a trip.

Fourth, memory and history. The AI remembers previous conversations, user preferences, and past decisions.

When you put all of this together — instructions, documents, tools, and memory — you get a context-engineered agent. This is what turns a simple chatbot into a smart, aware assistant."

**Riya (Question Overlay at 58.0s - 68.0s):**
"This sounds powerful. But how do we keep improving the context over time? If the AI gives a bad answer, do we have to fix everything manually?"

**Presenter:**
"No, Riya! That is the best part. We can set up automatic feedback loops. After each response, we check how good it was. If the context was missing something, the system learns to include it next time. Tools like Google's Vertex AI prompt optimizer can even do this automatically — they test different contexts and find the one that works best.

So remember: writing a good prompt is just the beginning. The real skill is building a rich context around it. That is Context Engineering — and it is the foundation of every great AI agent.

Thank you for watching the Prompt Chaining chapter! Subscribe to continue learning Agentic AI with me!"
